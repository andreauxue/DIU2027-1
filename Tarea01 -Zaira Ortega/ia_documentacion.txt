Para lograr que al hacer clic en los íconos te lleve directamente al objeto correspondiente en la sección de "OBJETOS", necesitamos hacer tres cosas:

1.  **Asignar un `id` único** a cada tarjeta de objeto dentro de la sección "OBJETOS".
2.  **Agregar un evento `onclick`** a los íconos en la sección "MÁS OBJETOS" que llame a una función de JavaScript.
3.  **Crear la función de JavaScript** que cambie a la sección de objetos y haga scroll suave hasta el `id` seleccionado.

Aquí tienes los cambios exactos que debes realizar en tu código.

### 3. Agregar la función JavaScript

Al final de tu archivo `index.html`, justo debajo de la función `mostrarSeccion`, agrega esta nueva función `irAlObjeto`:

```javascript
<script>
    // Función existente para cambiar de pestaña
    function mostrarSeccion(idSeccion) {
        const secciones = document.querySelectorAll('main > section');
        secciones.forEach(seccion => {
            seccion.classList.add('oculto');
            seccion.classList.remove('seccion-activa');
        });

        const seccionActiva = document.getElementById(idSeccion);
        seccionActiva.classList.remove('oculto');
        seccionActiva.classList.add('seccion-activa');
    }

    // NUEVA FUNCIÓN: Para ir al objeto específico
    function irAlObjeto(idObjeto) {
        // 1. Primero, mostramos la sección de objetos
        mostrarSeccion('objetos-seccion');
        
        // 2. Esperamos un pequeño instante (100ms) para que la sección sea visible
        // y luego hacemos scroll hasta el objeto.
        setTimeout(() => {
            const elemento = document.getElementById(idObjeto);
            if (elemento) {
                // Hace scroll suave y centra el objeto en la pantalla
                elemento.scrollIntoView({ behavior: 'smooth', block: 'center' });
                
                // Opcional: Efecto visual para resaltar el objeto al que llegamos
                elemento.style.transition = "box-shadow 0.5s ease";
                elemento.style.boxShadow = "0 0 20px 10px #FFE00C"; // Un brillo amarillo
                
                // Quitamos el brillo después de 2 segundos
                setTimeout(() => {
                    elemento.style.boxShadow = "5px 5px 0px rgba(0,0,0,0.8)";
                }, 2000);
            }
        }, 100);
    }
</script>
```

### 4. Actualizar el CSS (para que parezcan botones)

Para que el usuario sepa que los íconos son clickeables, debemos cambiar el cursor y añadir un efecto al pasar el mouse. Modifica la clase `.caja-icono` en tu `styles.css`:

```css
.caja-icono {
    border: 2px solid var(--color-negro);
    width: 70px;
    height: 70px;
    display: flex;
    justify-content: center;
    align-items: center;
    background-color: var(--color-blanco);
    
    /* NUEVOS ESTILOS */
    cursor: pointer; /* Cambia el cursor a una manito */
    transition: transform 0.2s ease, box-shadow 0.2s ease, background-color 0.2s ease; /* Transición suave */
}

.caja-icono:hover {
    transform: translateY(-5px) scale(1.05); /* Se levanta un poco */
    box-shadow: 3px 3px 0px var(--color-negro); /* Sombra estilo comic */
    background-color: #f0f4ff; /* Cambia ligeramente el fondo */
}
```

### ¿Cómo funciona esto?
1. El usuario hace clic en el ícono del hueso.
2. Se ejecuta `irAlObjeto('obj-hueso')`.
3. La función oculta el Inicio y muestra la sección Objetos.
4. Inmediatamente después, busca la tarjeta con `id="obj-hueso"`.
5. Hace un scroll automático y suave hasta esa tarjeta.
6. La tarjeta brilla con un borde amarillo durante 2 segundos para que el usuario sepa exactamente cuál es el objeto que buscaba.
